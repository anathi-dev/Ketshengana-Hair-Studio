## Project Overview
A fully responsive 6-page website for Ketshengana Hair Studio, aiming to transition manual WhatsApp bookings to an automated online system with a deposit calculator.

## Website Goals
- Increase bookings by 50%.
- Reduce manual WhatsApp inquiries by 40%.
- Showcase portfolio of braiding styles.

## Key Features
- **Dynamic Booking Form:** Select a service and instantly see the required 50% deposit.
- **Responsive Design:** Mobile-first approach ensuring compatibility across devices.
- **SEO Optimised:** Meta tags, alt text, and sitemaps included.
- **WhatsApp Integration:** Sticky button for quick client communication.
